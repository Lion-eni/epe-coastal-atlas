# Epe Coastal Environmental Governance & Spatial Intelligence Atlas

**Status:** In Progress  
**Location:** Epe Local Government Area, Lagos State, Nigeria  
**Started:** October 2026

## Project Overview

This project explores how geospatial intelligence, remote sensing, and participatory environmental observations can support coastal environmental governance and spatial decision-making in Epe, Lagos State, Nigeria.

## Objectives

- Establish a reproducible Python-based GIS workflow.
- Organise and assess administrative boundary, waterway, and waterbody datasets.
- Develop an evidence-graded inventory of fisheries and aquaculture locations.
- Assess the potential use of satellite-derived environmental indicators and Global Fishing Watch data.
- Develop spatial outputs relevant to coastal environmental planning and governance.

## Tools and Technologies

Python, GeoPandas, Rasterio, Shapely, PyProj, JupyterLab, QGIS/ArcGIS, and GitHub.

## Current Progress

- Python GIS environment established.
- Initial fisheries and aquaculture candidate inventory compiled.
- Boundary and supporting spatial datasets require further path verification and quality checks.
- Sentinel-2 analysis and Global Fishing Watch integration have not yet been completed.

## Planned Outputs

- Reproducible code and documented data sources.
- GIS maps and spatial analyses.
- Environmental governance research brief.

## Data and Research Integrity

Candidate locations will be validated before analysis. Data sources, coordinate reference systems, limitations, and verification status will be documented. Planned analyses are not presented as completed findings.
